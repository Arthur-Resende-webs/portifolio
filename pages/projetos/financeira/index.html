Sobre esta demonstração

O Finora é um projeto demonstrativo de organização financeira. Os nomes, saldos, receitas, despesas e orçamentos apresentados são fictícios.

Nenhuma informação financeira é salva. As interações servem para explorar a interface, os filtros e os relatórios.
